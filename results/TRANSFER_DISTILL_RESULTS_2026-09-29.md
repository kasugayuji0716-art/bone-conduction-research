## 1. CE（Whisper-small の CE 損失で学習した SE）を新しい認識器で評価

TAPS 比の CER 変化（test、改善話者数/10、p は話者単位）

| 認識器 | 入力特徴量 | TAPS | λ=0 | λ=0.5 | λ=2 | λ=10 |
|---|---|---|---|---|---|---|
| Whisper-large-v3-turbo | Whisper log-mel（128） | 0.1697 | +1.0%（3/10, n.s.） | −12.8%（10/10） | −17.3%（10/10） | **−16.6%**（10/10, p=0.002） |
| **Qwen3-ASR-1.7B** | **Whisper log-mel（128、WhisperFeatureExtractor）** | 0.1359 | +2.9%（1/10） | −12.9%（9/10） | **−18.2%**（10/10） | **−16.2%**（10/10, p=0.002） |
| **Zipformer（韓国語）** | **Kaldi fbank（80）** | 0.5422 | +5.1%（3/10, n.s.） | +18.8%（0/10） | +17.7%（1/10） | **+45.9%**（0/10, p=0.002） |

既存の認識器（`results/STEP0_RESULTS_2026-09-26.md` §3）と合わせると:

| 入力特徴量 | 認識器 | CE λ=10 の TAPS 比 |
|---|---|---|
| Whisper log-mel | Whisper base / small / medium / large-v3-turbo / FT | −2.1% / −14.8% / −14.1% / −16.6% / −17.2% |
| Whisper log-mel | Qwen3-ASR-1.7B | −16.2% |
| 波形（wav2vec2 CNN） | XLS-R / MMS-1B | +25.8% / +1.1% |
| Kaldi fbank | Zipformer | +45.9% |

- **Qwen3-ASR は Whisper とは別に学習されたモデル**（音声エンコーダ 24層・1024次元、LLM デコーダ）だが、特徴量抽出は WhisperFeatureExtractor（n_fft 400、hop 160、128 mel、log10、最大値 −8 で切り捨て、(x+4)/4）をそのまま使う（`Qwen/Qwen3-ASR-1.7B` の preprocessor_config.json で確認）
- → **CE の効果の転移は、アーキテクチャの系列ではなく、ASR の入力特徴量が Whisper の log-mel かどうかで分かれる**
- Qwen3-ASR + CE（λ=2: 0.111、λ=10: 0.114）は、喉マイクで FT した Whisper-small の SEなし（0.138）を下回る
- 先行研究との関係（2026-09-29 の文献調査）: D4AM（ICLR 2023）は「ASR 損失だけでは学習外の認識器に汎化しない」ことを示したが原因を特徴量とはしていない。arXiv 2607.11157（2026）は wav2vec2 と Whisper で好ましい補正の強さが違うと報告。偽音声検出では特徴量が攻撃の転移を決める報告がある（Deng et al., Interspeech 2022）。「系列ではなく特徴量で決まる」ことを、特徴量だけが同じ別モデル（Qwen3-ASR）で示した例は見つからなかった
- 実用上の意味（同日の調査）: Whisper の特徴量は公開の LLM 型 ASR の約3分の2（Qwen、Voxtral、Kimi など）が使うが、公開 ASR 全体では約3割、商用 API は分かる範囲で独自の Conformer 系。**ASR を選べない（クラウド API）場合、CE は効かない可能性が高い**
- 仕組みの検証は §3（単純な2つの仮説はいずれも否定）

## 2. 振幅統合（m4_med）を1つの SE-Conformer に蒸留（script 69）

教師 = 4つの SE（TAPS / Demucs / TSTNN / CE0）の振幅の中央値（位相は TAPS）。学習は TAPS pretrained から、早期終了は ASR を使わない dev の蒸留損失。

### 2.1 train の教師では学習が進まない
- dev 損失が TAPS の初期値（0.2878）から一度も下がらず、5エポックで早期終了（保存されたのは TAPS そのもの）
- 原因: 統合の元の SE はすべて TAPS train で学習済み。train の発話では SE の出力が気導音声に近く、SE 同士の差も小さい（log-mel L1、100発話ずつ）

| 分割 | TAPS–Demucs | TAPS–TSTNN | TAPS–気導音声 |
|---|---|---|---|
| train | 0.325 | 0.424 | 0.405 |
| dev | 0.424 | 0.483 | 0.586 |
| test | 0.418 | 0.468 | 0.570 |

- → train の教師には「SE 固有の誤りが打ち消し合う」効果がほとんど入らない。アンサンブルのメンバーは自分の学習データでは一致するため蒸留の教師が多様性を失うことは一般の機械学習で知られている（Nam et al., "Diversity Matters When Learning From Ensembles", NeurIPS 2021、要原典確認）

### 2.2 SE が見ていないデータの教師で学習した結果（test、TAPS 比、改善話者数/10）

|---|---|---|---|---|---|
| Whisper-base | −6.4% | −0.4% (5) | −0.5% (5) | +2.2% (4) | +2.6% (3) |
| Whisper-small | −9.8% | −2.9% (8) | −3.7% (9) | −1.6% (6) | −1.7% (7) |
| Whisper-medium | −9.8% | −2.8% (8) | −3.1% (9) | −2.0% (7) | −2.6% (7) |
| Whisper-large-v3-turbo | −10.5% | −3.7% (8) | −4.7% (10) | −4.6% (10) | −4.7% (10) |
| FT Whisper | −14.2% | −4.3% (8) | −5.1% (8) | −4.1% (7) | −6.4% (9) |

- dev 教師: TAPS dev 10話者のうち8話者（794発話、約2時間）で学習、2話者で早期終了。dev 損失は 0.2577 → 0.1922（振幅損失版は 0.5176 → 0.3994）
- VibraVox 教師: VibraVox speech_clean train の喉マイク 6,994 発話（約9時間、仏語）を 48k → 8k → 16k にして TAPS と帯域をそろえた（script 70）。早期終了は TAPS dev 全体
- 振幅損失（`--loss mag`）: 教師は「統合した振幅 + TAPS の位相」なので、波形 L1 を外して振幅だけを合わせる

### 2.3 結論
- どの蒸留も、**Whisper 系で振幅統合の効果の3分の1〜半分**しか残らず、**非 Whisper 系では効果が消えるか悪化**する（「どの認識器にも効く」性質が失われる）
- データ量を増やしても、ドメインの違う VibraVox では非 Whisper 系が大きく悪化した
- → 今あるデータでは蒸留は見込みが薄いため打ち切る。統合は SE を4つ動かしたまま使う前提で、推論時間を script 71 で測る（SE は各 1000 万パラメータ前後、ASR は数億〜20億パラメータ）

## 3. 仕組みの検証（script 72）: 単純な説明は2つとも否定

TAPS 比（test、CE は λ=10。Zipformer は空白も除去した CER）

| 条件 | Whisper-small | Qwen3-ASR | XLS-R | Zipformer |
|---|---|---|---|---|
| CE | −14.8% | −16.1% | +25.8% | +74.4% |
| CE を 40 / 80 / 160 サンプル遅らせる | −14.5 / −13.6 / −14.1% | −15.9 / −16.0 / −14.9% | +24.6 / +24.7 / +24.1% | +75.0 / +74.7 / +74.8% |
| CE のうち Whisper に見える部分だけ（`ce_visible`） | −14.5% | −15.9% | +24.6% | +75.6% |
| CE のうち Whisper が切り捨てる部分だけ（`ce_invisible`） | +0.2% | −0.2% | +0.1% | −0.3% |

（TAPS 自体を 80 / 160 サンプル遅らせた影響は ±1.3% 以内。遅らせた CE と同じだけ遅らせた TAPS の比較でも、Whisper-small −13.2〜−13.6%、Qwen3-ASR −13.9〜−16.5%、XLS-R +24.9〜+25.2%、Zipformer +75.6〜+76.0%）

- **仮説1（Whisper の 10 ms フレーム格子への依存）は否定**: 半フレーム（80 サンプル）ずらしても効果・悪化ともほぼ変わらない
- **仮説2（Whisper が切り捨てる約 80 dB 下の領域の改変）は否定**: CE − TAPS の差のエネルギーのうち切り捨て領域に入るのは 0.0000（1000発話平均、Whisper-small の 80 mel で判定、切り捨て領域のビンは全体の 0.9%）。見える部分だけ残すと CE とほぼ同じ、切り捨て部分だけ残すと TAPS とほぼ同じ
- → CE の変化はすべて、どの認識器からも「見える」強い成分で起きている。同じ変化が、Whisper の特徴量を使う認識器には有益で、それ以外には有害
- 残る仮説: (a) 特徴量の細部（窓、mel フィルタの形と正規化、対数、発話ごとの正規化: Whisper は最大値基準、Kaldi は平均・分散正規化）の違い、(b) 音声エンコーダが学習で身につけた感度の違い（Qwen3-ASR のエンコーダは一から学習と報告されているが、学習データや方法が Whisper に近い可能性）。切り分け案: Zipformer の入力直前で正規化だけを Whisper 方式に替える、特徴量が Whisper と同じで学習データの違う認識器を加える

## 4. 推論時間（script 71、GPU: RTX PRO 6000 Max-Q、test 先頭 60 発話のうち 55 発話、平均 10.5 秒）

|---|---|---|
| TAPS / CE0 / TSTNN | 19.9 / 10.4 / 119.1 ms | 0.0019 / 0.0010 / 0.0114 |
| **Demucs** | **836.7 ms** | 0.0800 |
| 統合（STFT → 中央値 → iSTFT） | 2.5 ms | 0.0002 |
| 4つの SE ＋統合の合計 | 988.6 ms | 0.0945 |

| 認識器 | TAPS＋ASR | 4SE統合＋ASR | 倍率 |
|---|---|---|---|
| Qwen3-ASR-1.7B | 2,653 ms | 3,615 ms | 1.36 |

- 4つの SE の合計でも RTF 約 0.09（実時間の約10倍速）で、オフライン処理なら実用的。ただし軽い認識器と組み合わせると全体の時間が何倍にもなる
