# 計画: 喉マイク音声の何が認識を難しくするのか（入れ替え実験、2026-11-05）

状態: 計画のみ。スクリプトは未作成、実験は未実行。

## 問い

喉マイク音声の Whisper-small の CER は 0.447、同じ発話の気導音は 0.126 である。この差を生む信号の性質を特定する。

これまでにわかっていること:

- 平均的な周波数特性（固定のイコライザ 1 つ）と 4 kHz の帯域制限では、難しさは再現しない。疑似喉マイクの CER は韓国語 0.130、仏語 0.037 で、本物は 0.448、0.296（GENERATIVE_RESULTS §7.19、script 92）。
- 生成×4 のあとも、激音（ㅋㅌㅍㅊ）の字母誤りが平音より多く残る（論文 4.2 節、script 93）。確かなのは Whisper-small だけで、探索的な結果である。
- 無声区間の高域は、生成×4 でも融合でも気導音より弱いまま残る（§7.18、script 91）。

この計画は、気導音の一部を本物の喉マイクに入れ替えて CER を測る。どの部分を入れ替えると CER が上がるかで、原因の場所を絞る。

## 共通の設定

### データ

- TAPS test の 1,000 発話（10 話者）。喉マイクと気導マイクの同時収録の組を使う。
- 平均特性 H(f) と区間別の特性は TAPS train から求める。test は推定に使わない。
- 学習は一切しない。すべて信号の加工と認識だけである。

### 出発点（基準の音声）

基準は「気導音を 4 kHz で帯域制限した音声」（以下、気導LP）とする。帯域制限は CER をほぼ変えないことがわかっている（疑似喉マイク 0.130 対 気導 0.126）。すべての条件で 4 kHz 以上を 0 にし、帯域制限の影響を全条件から外す。

### 平均特性を合わせた喉マイク

入れ替えに使う喉マイク音声は、先に平均特性をそろえる。STFT（512 点、シフト 128 点、Hann 窓）の各係数を 1/H(f) 倍し、4 kHz 以上は 0 にする。以下、これを「補正喉マイク」と呼ぶ。

理由: 平均特性は原因でないことがわかっている。そろえておけば、入れ替えで CER が上がった分は「平均では表せない違い」から来たと言える。

### 指標

再現率 g（入れ替えで、喉マイクの難しさのうち何割が再現したか）:

    g = (CER_条件 − CER_気導LP) / (CER_補正喉マイク − CER_気導LP)

g = 0 は難しさが全く再現しないこと、g = 1 は補正喉マイクと同じ難しさを表す。分母に本物の喉マイクではなく補正喉マイクを使うのは、平均特性を除いた後の難しさを基準にするためである。

### 2 つの向き（2026-11-05 追記、実験 0 の結果を見る前）

各実験を 2 つの向きで行う。

- **壊す向き**（d）: 気導LP の一部を補正喉マイクに入れ替える。CER が上がれば、その成分の劣化は難しさを生むのに十分である。指標は上の g。
- **救出の向き**（r）: 補正喉マイクの一部を気導LP に戻す。CER が下がれば、その成分を直すことは難しさを解くのに役立つ。指標は回復率 h。

    h = (CER_補正喉マイク − CER_条件) / (CER_補正喉マイク − CER_気導LP)

同じ成分が両方の向きで効けば（g と h がともに大きい）、その成分を原因と強く言える。片方だけなら、成分の間の相互作用を疑う。救出の向きで h が大きい成分は、喉マイク用の前処理が直すべき対象の候補になる。

実験で使う 2 つの音声は、実験 0 で作った気導LP（taps_airlp）と補正喉マイク（taps_threq）そのものである。どちらも 4 kHz 以上が 0 で、RMS は同じ値にそろっている。

### 認識器

- Whisper-small、large-v3-turbo、Qwen3-ASR-1.7B（Whisper 形式の対数メル入力）
- MMS-1B（波形入力の CTC、系統の異なる認識器）

認識は script 66 の `asr` で行い、新しい条件の集合を `SETS['swap']` として加える。

### 統計

- 話者ごとの平均 CER で両側 Wilcoxon 符号順位検定（n = 10、補正前の最小 p は 0.002）。
- 条件の対ごとに 4 認識器の p 値を Holm 法で補正する。
- 字母誤り率は script 93 の方法で求める。

### 事前に固定すること

論文 4.2 節の激音の分析は、比較を結果から選んだため探索的だった。この計画では、条件・比較・予測をこの文書で先に固定し、結果を見てから比較を追加しない。追加した比較は「事後」と明記する。

## 実験 0: 前提の確認

1. **時間のずれ。** 喉マイクと気導マイクのずれを、発話ごとに相互相関（包絡、±50 ms）で求める。ずれの中央値と分布を報告する。これまでのスクリプト（91・92・93）は、ずれが無いと仮定していた。ずれが 1 フレーム（8 ms）を超える発話が多ければ、補正してから入れ替える。
2. **基準の CER。** 気導、気導LP、疑似喉マイク（script 92 と同じ）、補正喉マイク、本物の喉マイクの CER を 4 認識器で測る。
3. **補正喉マイクの位置づけ。** 補正喉マイクの CER が本物の喉マイクとほぼ同じなら、平均特性の補正は難しさを変えないことの確認になる。大きく下がれば、それ自体が結果である（平均特性は、気導音には効かないが喉マイクには効く）。

## 実験 1: 時間の細かさの段階

問い: 喉マイクと気導音の違いを、どの時間の細かさで真似れば難しさが現れるか。

各 STFT 係数で、対数振幅の差を求める。

    R(t, f) = log|補正喉マイク(t, f)| − log|気導(t, f)|

R を時間方向に幅 τ でなめらかにし、気導音の振幅に掛ける。位相は気導音のものを使う。

    Y(t, f) = |気導(t, f)| · exp(R_τ(t, f)) · e^{j∠気導(t, f)}

| 条件 | 内容 |
|---|---|
| τ = 発話全体 | 発話ごとの固定イコライザ |
| 区間別 | 有声・無声・無音（気導音の pYIN と 40 dB の閾値、script 91 と同じ）ごとの固定イコライザ。train で推定 |
| τ = 1 s、300 ms、100 ms、30 ms | 時間変化する特性を段階的に細かくする |
| τ = 0 | 補正喉マイクの振幅と気導音の位相（オラクル） |
| 対照: 位相だけ入れ替え | 気導音の振幅と補正喉マイクの位相 |

救出の向き: 補正喉マイクから同じ差を引く。位相は補正喉マイクのもの。

    Y(t, f) = |補正喉マイク(t, f)| · exp(−R_τ(t, f)) · e^{j∠補正喉マイク(t, f)}

条件は τ = 発話全体、区間別、1 s、100 ms、30 ms の 5 つ（τ = 0 の救出は「位相だけ入れ替え」と同じ音声になるので作らない）。τ = 発話全体の救出は、喉マイクに発話ごとのイコライザをかけることに当たる。

予測（事前に固定）: g は τ が小さいほど上がる。h も τ が小さいほど上がる。区間別で g が大きく上がれば、原因は「音の種類による伝わり方の違い」である。τ = 0 で g がほぼ 1、位相だけの入れ替えで g がほぼ 0 なら、難しさは振幅にある。

R は 4 kHz 未満だけで求める（4 kHz 以上はどちらも 0 なので対数が定義できない）。無音区間では気導音の振幅が小さく R が極端な値になるので、両方の振幅に同じ下限（発話内の最大から −80 dB）を設けてから差をとる。

注意: R の時間平均は発話ごとに 0 にならない。τ = 発話全体の条件が、この発話ごとのずれの影響を示す。

## 実験 2: 区間の入れ替え

問い: 声の区間と息の区間のどちらの違いが効くか。激音の仮説を直接確かめる。

気導音のうち、選んだフレームだけを補正喉マイクに入れ替える（複素係数ごと。切り替えは 3 フレームの移動平均でなめらかにする。script 91 の tmask と同じ）。

| 条件 | 入れ替えるフレーム |
|---|---|
| 無声 | 気導音で無声と判定したフレーム（約 12%） |
| 有声 | 有声と判定したフレーム（約 76%） |
| 無音 | 無音と判定したフレーム（約 12%） |
| 対照: 無声をずらす | 無声のマスクを発話内で時間方向に巡回シフトしたもの（同じ割合、別の位置） |
| 対照: 有声をずらす | 同上 |

救出の向きでは、補正喉マイクのうち同じフレームを気導LP に戻す。5 条件とも両方の向きで作る（計 10 条件）。ずらしたマスクは、発話ごとに乱数で決めた量だけ巡回シフトする（script 91 の vshift と同じ方法）。

§7.20 では、有声マスクがフレームの 83% を占め、フレームの量と位置が交絡した。ここでは、ずらしたマスクとの直接比較を主な比較にする。

主な比較（事前に固定）:

1. 無声 対 無声をずらす（同じ量で、無声の位置が効くか）
2. 有声 対 有声をずらす
3. 無声と無声をずらすの両方で、激音・平音・摩擦音の字母誤り率

予測: 無声の入れ替えは、ずらした対照より CER を上げ、特に激音と摩擦音の字母誤りを増やす。救出の向きでは、無声区間を気導に戻すと、ずらした対照より CER が下がり、激音の字母誤りが減る。この予測が外れれば、激音の残りは息の成分の欠落以外から来ている。

## 実験 3: 帯域の入れ替え

問い: どの帯域の違いが効くか。

気導LP の振幅のうち、1 つの帯域だけを補正喉マイクの振幅に入れ替える。位相は気導音のもの。帯域の境目は 1 ビン（31.25 Hz）幅のなめらかな切り替えにする。

| 条件 | 入れ替える帯域 |
|---|---|
| B1 | 0〜0.5 kHz |
| B2 | 0.5〜1 kHz |
| B3 | 1〜2 kHz |
| B4 | 2〜4 kHz |

救出の向き: 補正喉マイクの振幅のうち 1 つの帯域だけを気導LP に戻す。位相は補正喉マイクのもの。B1〜B4 の両方の向きで計 8 条件（当初の「逆: B1〜B3」は、救出の B4 とほぼ同じなので救出の向きに置き換えた）。

予測: 帯域ごとの g の和は 1 にならない（帯域の間に相互作用がある）。それでも、g が大きい帯域から順に調べる対象を絞れる。

## 実行の順序と判断

1. 実験 0 を先に行う。時間のずれが大きければ、補正の方法を決めてから進む。補正喉マイクの CER がほぼ気導LP まで下がった場合は、平均特性が喉マイクには効くことになり、この計画の前提が変わる。そのときは立ち止まって計画を見直す。
2. 実験 1 と 2 は互いに独立なので、並行して行える。実験 3 は 1 の結果を見てから、帯域の切り方を決めてもよい（その場合、切り方の変更は事後と明記する）。
3. 結果は `results/THROAT_DIFFICULTY_RESULTS_2026-11-xx.md` に書く（研究ハブの同期の対象）。

## 実装

- `scripts/95_throat_swap.py`。モードは `align`・`make0`・`summary0`（実験 0）、`stats`（train 500 対で区間別の R の平均を推定）、`make`（実験 1〜3 の音声）、`summary`（集計）。
- 実験 1〜3 の各条件は、script 92 と同じく BCR_DATASET 用のデータセット `data/raw/taps_sw_<条件>` として作り、script 66 の `--conds no_se` で認識する。
- 区間の判定は気導音の pYIN（STFT と同じ 128 点のシフト）と、気導LP のフレームのエネルギー（最大から 40 dB 未満を無音）で行う。
- 条件数は 31（実験 1 で 13、実験 2 で 10、実験 3 で 8）。学習はない。認識は 4 認識器 × 31 条件 × 1,000 発話で、自動ジョブ E7c_throat_swap として実験 0 の後に 1 つずつ行う。Whisper-small を全条件で先に行い、次に MMS、turbo、Qwen3 の順にする。Whisper-small の 1,000 発話は、GPU を共用した状態で約 1 時間だった。全体では 1〜2 日かかる見込みである。

## この計画で答えられないこと

- 入れ替えは「気導音の一部を喉マイクにすると難しくなるか」を測る。原因の候補を絞れるが、物理的な仕組み（首の組織での伝わり方など）までは示さない。
- 補正喉マイクの 1/H(f) は、4 kHz 未満でも H が小さい帯域で雑音を持ち上げる。実験 0 で、H の最小値と補正後の無音区間の床を確認する。
- TAPS（韓国語、1 種の喉マイク）だけの結果である。VibraVox で同じ実験を行うかは、TAPS の結果を見て決める。
