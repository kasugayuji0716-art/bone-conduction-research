## 対応（2026-11-19）

| 指摘 | 対応 |
|---|---|
| A. 接続語の書き出し 3 段落 | 主語から書き出した。「生成×4とCE-SEの出力は，…組み合わせる」「融合が生成×4から何を変えたかは，…」「融合による音響特徴量の変化は，次の3つの量で測る」 |
| B. TAPS | 初出で Throat and Acoustic Pairing Speech（TAPS） |
| B. FFT・RMS | どちらも1回しか使わないので略語をやめた。「窓長が512，1024，2048点」「音量は，二乗平均平方根が…中央値になるように」 |
| B. FT | 初出で「fine-tuning（FT）済みのFT Whisper」 |
| B. CTC | 他の略語と同じ形「コネクショニスト時系列分類（connectionist temporal classification: CTC）」に。理由が違えば再指摘されるはず |
| C. STFT の条件 | 2.2節は「窓長512点，シフト128点のHann窓でSTFTをかけ」と文に。2.3節は「2.2節と同じ窓長とシフトで」 |
| C. D（257点），LPC の条件 | 「257点の$D$を」「係数0.97でプリエンファシスをかける。窓長25 ms，シフト10 msのハミング窓で」 |
| C. 結果の数値の括弧 | 「CERを1.8〜8.0%下げた」「補正後の$p$はいずれも0.020以下」「0.007以下」、計算量の節は文に分けた |
| D. はるかに | 「本物の喉マイクと気導マイク音声の差0.322の約100分の1」（表2: 0.448−0.126） |
| D. ほぼ改善しなかった | 「−1.7〜+3.1%で，改善と悪化が混在した」（表5: small・medium・Qwen3で悪化、turbo・FTで改善） |
| D. 重い | 「重い」を削除。時間は同じ節の次の文（約4.1秒→約0.41秒）にある |
| E. 考察の段落 | 「したがって」を外し「乱数初期値との比較から言えるのは，…ことである」に。TAPS SE の文は「パラメータ数が1210万と小さい」に。文の長さはほぼ同じなので、再指摘されるかもしれない |

ページ数を8に保つため、指摘外で1か所だけ短くした: 考察「効果が特定の区間に集まる証拠は得られなかった」→「証拠はなかった」。
