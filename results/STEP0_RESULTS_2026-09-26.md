## 2. 対照1：2つのSE出力の平均（アンサンブル効果の切り分け）

| TAPS + CE0（CE損失なしで追加学習） | −3.4%（10/10） | −1.5% / −1.4% | −1.6% / −2.3% |
| TAPS + CE10（= α=0.5） | −12.9%（10/10） | −6.1% / −5.7% | −3.9% / −5.6% |

- CE0 は単体では TAPS より悪い（下の §3）が、TAPS と平均すると全認識器で改善 → **平均そのものに効果がある**
- TAPS+CE10 は TAPS+CE0 よりさらに良い（small −9.8%、MMS −4.7% / −4.3%、XLS-R −2.4% / −3.3%、test/dev とも有意）→ 平均効果だけでは説明しきれない上積みがある
- **未解決の交絡**: CE10 は CE0 より TAPS から遠い（多様性が大きい）ため、上積みが「CE の変化の中身」によるのか「相手が大きく違うこと」によるのかは未分離。ASR損失なしで TAPS と大きく異なる SE（例: TAPS 公開の Demucs）との平均が次の対照

- Whisper-small/medium/FT は λ とともに単調に改善。Whisper-base は有意な改善なし（最良 λ=2 で −3.2%, p=0.11）。MMS・XLS-R はどの λ でも TAPS を下回らない
- **α 混合との比較**: small/medium/FT では α=0.5 と最良 λ がほぼ同値（例: medium 0.1733 vs 0.1686）。一方 base（0.2499 vs 0.2639）、MMS（0.3283 vs 0.3501）、XLS-R（0.2130 vs 0.2306）では **λ をどう選んでも α 混合の改善に届かない**
- → 「CE の変化を小さく抑えれば認識器に依らず効く」という仮説は**不成立**。非Whisper系・学習系列外の改善は、主に2出力の平均（§2）から来ている

## 6. まとめと次の一手

1. CE の出力を TAPS と半分ずつ平均すると、**学習に使っていない認識器を含む6つすべてで TAPS より良くなる**（test/dev とも）
2. ただしその主因は「CE の変化を弱めたこと」ではなく、**2つの異なる SE 出力の平均**（λ を下げても同じ効果は出ない）。**ASR損失を使わない TAPS SE-Conformer と TAPS Demucs の振幅平均でも6認識器すべてが改善**する（§2b）。CE の中身による上積みは主に Whisper 系で見られ、非Whisper 系では小さい
3. 合成高域は Whisper系には有害・XLS-R には必要で、「どの認識器にも良い高域」は存在しない可能性がある
4. 修士テーマ（ASR非依存SE）への示唆: 1つのASR損失を弱めるより、**性質の異なる複数の SE 出力・複数の ASR 損失を組み合わせる**方向（Step 2、Step 3(a) の出力選択）が有望

次にやること（優先順）
- ~~多様性の対照~~（§2b で完了）
- **振幅平均の一般化**: 3つ以上の SE（TAPS / Demucs / TSTNN / CE0）の振幅平均、平均の重み、平均する領域（振幅・log-mel）を比べる。ASR を使わずに組み合わせ方を決められるか（例: dev の CER ではなく SE 出力どうしの一致度で重みを決める）
- **1モデル化**: 平均出力を教師に1つの SE へ蒸留し、平均の効果が1モデルで再現できるか（推論コストを TAPS と同じにする）
- FT Whisper の話者別改善と「学習話者からの距離」の相関（§5 の仮説検証）

## 限界

- α の最良値は認識器ごとに dev で確認したが、「全認識器で使う1つの α」を学習に使っていない系列の認識器だけで選ぶ手順（leave-one-family-out）はまだ行っていない
- 出力の平均は SE を2つ動かすため推論コストが2倍。提案手法ではなく分析として扱う
- 学習は各 λ 1回のみ（seed 分散未評価）。韓国語 TAPS、雑音なし音声のみ
